Why keep a small site?

A personal site should make it easy to publish ideas without adding unnecessary machinery. The first version of this site keeps the content in Markdown and lets Hugo build the pages.

Fewer moving parts

Static content is easy to version, review, and move between hosts. That simplicity leaves more attention for the writing itself.

Room to grow

Categories, tags, search, and publication navigation provide useful structure while the collection is still small.
